Daimon Technologies Website

Daimon Technologies India Private Limited is a technology company focused on cloud software, dashboard solutions, application development, AI projects, and research in battery and power management. We build secure, scalable, and future-ready digital solutions for modern businesses.

🌐 Project Overview

This repository contains the official website for Daimon Technologies.

The website features a modern glassmorphism design inspired by premium UI concepts, with smooth animations and a fully responsive layout.

✨ Features
Glassmorphism UI design
Smooth navigation hover effects
Animated background gradients
Interactive glass cards
Custom cursor effects
Responsive design (mobile, tablet, desktop)
Counter animations
Testimonials slider
Contact form with validation
Smooth scrolling
Parallax effects


🛠 Technologies Used
HTML5
CSS3
JavaScript
Responsive Web Design
Modern UI Animations

🚀 How to Use
Clone or download this repository.
Open index.html in your browser to view locally.
For deployment:
Upload files to your hosting server (public_html or www folder).
Or deploy using GitHub Pages.
